# 3D Director

面向 AI 视频前期预演的轻量级 3D 导演台。它让导演、分镜与运营同学先在统一的 3D 空间中搭建角色、场景和机位，再通过时间轴组织角色运动、关键帧和机位切换，快速输出可沟通的镜头参考。

**在线预览：** [3d-director-demo-kairos.vercel.app](https://3d-director-demo-kairos.vercel.app)

## 它解决什么问题

AI 视频生成前，创作者经常需要先对角色站位、空间关系、镜头视角和运镜节奏达成共识。传统 DCC 软件学习和制作成本高，而文字分镜又难以准确表达空间和镜头意图。

3D Director 提供一个更轻量的预演工作流：

1. 在设计模式导入模型、添加角色与机位，完成场景搭建。
2. 切换到动画模式，把需要动画化的资产插入时间轴。
3. 通过关键帧编辑角色运动、姿势与机位参数。
4. 用机位序列控制播放和导出时的镜头切换。
5. 保存快照或视频录制结果，作为后续创作与沟通的参考。

## 核心能力

### 设计模式

- 导入 GLB / OBJ 资产，添加角色、几何体与机位
- 对象与机位的移动、旋转、缩放、显示隐藏、锁定与删除
- 角色白模、姿势预设、FK / IK 骨骼控制与局部姿势调节
- 机位自由朝向、注视目标、焦距和视角锁定
- 场景网格、地面、全景图和材质参数编辑
- 资产组合、批量显示隐藏、锁定、对齐、解组与右键操作

### 动画模式

- 资产按需插入时间轴，而不是与资产列表自动同步
- 对象、角色、骨骼和机位关键帧记录与编辑
- 自动插帧、手动插帧、入点 / 出点和时间轴缩放
- 角色沿直线或可编辑贝塞尔路径移动，并根据路径切线自动转向
- 机位序列控制播放和导出时的镜头切换
- 时间轴播放预览、快照保存和视频录制管理

## 使用方式

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
```

## 项目结构

```text
src/
├── app/         # 应用壳层、主布局与全局样式
├── components/  # 左右面板、底部工具栏、时间轴与视窗组件
├── domain/      # 项目数据模型、时间轴采样、机位和骨骼业务规则
├── export/      # 快照与动画导出逻辑
├── store/       # Zustand 项目状态与编辑操作
└── three/       # Three.js 场景、模型加载、机位、材质与骨骼运行时
```

更详细的职责边界见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。

## 技术栈

- React 19 + TypeScript
- Vite
- Three.js
- Zustand
- Lucide Icons
- Vercel

## 当前边界

该项目是产品预演 demo，重点验证 3D 导演台的设计和动画工作流。它不替代 Blender、Maya、Unreal 等完整 DCC 工具；多人协作、工程文件持久化和专业级视频渲染仍属于后续能力。
